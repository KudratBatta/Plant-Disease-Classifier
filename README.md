# Plant Disease Prediction using CNN

This repository contains a **Convolutional Neural Network (CNN)** model built with Python for predicting plant diseases from images. The model is trained on the **PlantVillage Dataset** to classify healthy and diseased plant leaves.

---

## 📂 Dataset

The model uses the **PlantVillage Dataset** from Kaggle:  
[PlantVillage Dataset on Kaggle](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset)

The dataset contains images of different plant species with various diseases, along with healthy leaf images.

---

## ⚡ Features

- Predicts plant diseases from leaf images.
- Supports multiple plant types (e.g., apple, potato, tomato).
- Uses Convolutional Neural Network (CNN) for high accuracy.
- Easy to use: input an image and get the disease prediction.
